Day 7/14 — Generation Pipeline Architecture
RAG From Zero → Production
🔍
Hybrid Retrieval + BGE Reranker
Dense (Qdrant) + BM25 fused via RRF → top-10 candidates. Cross-encoder reranks to top-5.
✓ Reused from Day 6
📝
Citation-Aware Generator
Gemini structured output enforces Answer(text, citations[doc_id, page, quote]). Every claim must point to a source passage.
⚠ +20% latency · structured output can fail → fallback
🧑‍⚖️
Self-RAG Scorer (LLM-as-Judge)
Second Gemini call asks: "Is this answer supported by the context?" Returns confidence in [0, 1].
⚠ +1 LLM call per query · avg confidence 0.87 on FinanceBench
🔬
NLI Hallucination Detector
Local nli-deberta-v3-base checks each sentence: does the cited quote entail the claim? No API calls.
✓ No API cost · ~180 MB, CPU-OK ⚡ Weak on numeric reasoning
🔄
Corrective Regeneration Loop
If hallucination rate > 25%: re-retrieve with 2× docs, regenerate. Max 2 iterations. Best answer kept.
⚠ Can 2× latency · fired on 20% of queries
Structured Answer
text · citations[doc, page, quote] · confidence · hallucination_rate · iterations
